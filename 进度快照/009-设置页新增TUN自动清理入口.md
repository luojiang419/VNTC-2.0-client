# 009-设置页新增TUN自动清理入口

## 已完成内容

- 设置弹窗新增“自动清理无用 TUN 虚拟网卡”开关。
- 设置保存时会持久化 `cleanupUnusedTunOnLaunch`。
- 用户首次从关闭切换为开启并保存后，会立即执行一次清理。
- 新增 `formatTunAdapterCleanupResult`，根据清理结果显示 SnackBar：
  - 不支持当前系统。
  - 未发现可清理网卡。
  - 已清理数量、保留配置网卡数量。
  - 未清理但跳过正在使用或无法删除的网卡数量。
- 设置说明中明确清理范围：仅处理本客户端生成且未被配置引用的 `vntc-*` 网卡。

### 设置保存流程

修改前：

```dart
await controller.saveSettings(result);
```

修改后：

```dart
await controller.saveSettings(result);
final shouldRunCleanup =
    result.cleanupUnusedTunOnLaunch &&
    !cleanupWasEnabled &&
    controller.settings.cleanupUnusedTunOnLaunch;
if (!shouldRunCleanup) {
  return;
}

final cleanupResult = await controller.cleanupUnusedTunAdapters();
```

### 设置页新增开关

新增：

```dart
SwitchListTile(
  contentPadding: EdgeInsets.zero,
  value: cleanupUnusedTunOnLaunch,
  title: Text(
    t(
      '自动清理无用 TUN 虚拟网卡',
      'Automatically clean unused TUN adapters',
    ),
  ),
  onChanged: (value) =>
      setState(() => cleanupUnusedTunOnLaunch = value),
),
```
