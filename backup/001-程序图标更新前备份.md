## 风险点

- 当前工作区存在本次任务外的未提交改动，发布时必须只纳入本次图标和版本发布相关文件。
- `dist/` 中的文件用于 Inno Setup 打包，但可能不属于 Git 跟踪范围，需要作为发布资产处理。
- 若本机缺少 Inno Setup 编译器，只能生成 zip 包并说明安装包构建阻塞。
